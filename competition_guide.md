# Competition Website Excellence Guide: AIAA Design/Build/Fly (DBF)

This guide provides a strategic analysis of top competition websites to help future LLM models and developers build a website that exceeds all current standards.

## 1. Core Content Pillars
The best websites tend to organize information into these key areas:

| Pillar | Description | Best Practice |
| :--- | :--- | :--- |
| **The Aircraft** | Highlighting design, specs, and named aircraft. | Give the plane a personality (e.g., MIT's *"Ariel the Little Merplane"*). |
| **The Team** | Showing subteams (Aero, Structures, etc.) and diversity. | Use stats: "60+ Members", "13 Disciplines", "6 Subteams" (UW style). |
| **The Mission** | Explaining the AIAA DBF rules and current challenge. | Use diagrams to simplify complex flight profiles. |
| **The Record** | Proving prestige through history and victories. | High-visibility "Victories" or "Top 10" section (GT/MIT style). |
| **The Sponsors** | Professional acknowledgment of financial/tool support. | Use tiered tables (Silver/Gold/Platinum) with clear benefits. |

## 2. Visual & Media Strategy
To truly "WOW" the user, the website should feature:

- **Hero State**: A high-speed action shot of the aircraft in flight or a stunning 3D CAD render.
- **Action Shots**: "Build" photos showing students in the lab (carbon fiber layups, soldering, testing).
- **Technical Prowess**: Embed CFD (Computational Fluid Dynamics) plots or FEA (Finite Element Analysis) results to show "we know what we're doing."
- **Typography**: Use modern, clean sans-serif fonts (like Inter or Roboto) rather than stock university styles.

## 3. Technical Implementation & UX
- **Performance**: Use modern frameworks like **Astro** (for speed) or **Next.js** (for rich interaction).
- **Micro-animations**: Subtle hover effects on sponsorship logos and navigation items.
- **Scrollytelling**: Link aircraft specs or mission steps to scroll progress (see Cornell's minimalist flow).
- **Responsive**: Essential for recruiting during fly-offs (recruiters and students check on mobile).

## 4. Strategic Differentiators
How to beat the current top 7:

1.  **Interactive CAD**: Instead of just images, use a library like `Three.js` or `react-three-fiber` to allow users to rotate the aircraft model in 3D.
2.  **Live Progress Bar**: A "Mission Progress" tracker showing where the team is in the Design -> Build -> Test cycle.
3.  **Alumni Network Hub**: A dedicated section for alumni stories to show career path success (Boeing, SpaceX, NASA) to attract high-caliber students.
4.  **Recruiting Funnel**: A "Join Us" flow that is as professional as a job application, including subteam descriptions and skill requirements.
